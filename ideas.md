# BK Authority Media — Design Direction

## Stylistic approaches considered

### Theme Name: Editorial Cutroom
Very dark cinematic portfolio with sharp editorial typography, film-strip rhythm, and restrained amber accents. It feels like a professional post-production studio rather than a generic freelancer page.

**Probability:** 0.07

### Theme Name: Sunlit Storyboard
Bright documentary-inspired layout with warm paper tones, handwritten annotations, and a friendly creator-led personality. It emphasizes approachable storytelling and behind-the-scenes craft.

**Probability:** 0.06

### Theme Name: Signal / Motion
A high-contrast visual system inspired by broadcast graphics, with electric cyan and red markers, modular content blocks, and kinetic transitions. It positions the studio as fast, technical, and trend-aware.

**Probability:** 0.05

## Chosen approach: Editorial Cutroom

### Design Movement
Contemporary cinematic editorial design, borrowing from film title cards, contact sheets, and premium post-production workspaces.

### Core Principles
The page should feel direct, cinematic, and deliberate. Strong typographic hierarchy should do more work than decorative UI. Video work should be the visual focus, while the interface remains quiet and confident. Every section should guide the visitor toward a clear action: view work or start a WhatsApp conversation.

### Color Philosophy
Use near-black charcoal as the studio surface, warm bone white for readable text, and one ownable amber-gold accent that feels like a timeline playhead or light leak. The palette should communicate craft, focus, and premium finishing without relying on purple gradients or generic neon effects.

### Layout Paradigm
Use an editorial vertical rhythm with oversized type, asymmetrical project rows, framed media links, and offset metadata. Avoid a uniform card grid. The portfolio should feel like a curated reel, with each project receiving a distinct visual beat.

### Signature Elements
Amber “cut marks” and timeline-like rules will appear beside section labels. Project cards will use numbered edit markers and restrained hover movement. The WhatsApp CTA will feel like a production brief handoff rather than a generic contact button.

### Interaction Philosophy
Interactions should be quick and purposeful. Hover states reveal format and service details; buttons use clear action language. No interaction should delay access to the work or overwhelm the visitor with animation.

### Animation
Use short opacity and translate transitions for project rows, subtle scale on media frames, and a slow marquee only where it supports the sense of motion. Respect reduced-motion preferences. Avoid perpetual glow, bouncing buttons, or excessive parallax.

### Typography System
Use a condensed display face for headlines and a clean grotesk sans-serif for body copy and metadata. Suggested web-safe pairing: `Arial Narrow`, `Impact`, or a loaded condensed font for display, with `Inter` avoided in favor of `Helvetica Neue`, `Arial`, and system sans-serif for supporting text.

### Brand Essence
BK Authority Media turns raw footage and ideas into high-impact social video for brands, creators, and businesses that need content with momentum. Personality: cinematic, focused, dependable.

### Brand Voice
Headlines should be concise and visual. CTAs should be confident and practical. Microcopy should sound like a production partner, not a sales funnel.

Example lines: “Make the footage move.” and “Send the brief. Let’s cut something worth watching.”

### Wordmark & Logo
Use a custom typographic lockup where “BK” is treated like two bold edit frames, followed by a compact `AUTHORITY MEDIA` wordmark. The generated mark should be a bold abstract pair of interlocking cut brackets without text, suitable for the header and favicon.

### Signature Brand Color
**Playhead Amber — #E7A83E.** It evokes the active point on an editing timeline and is distinctive against charcoal.

## Style Decisions

- Portfolio frames will feel like real editorial stills through more varied compositions, lighting, and motion textures instead of repeating one abstract graphic treatment.
- The BK mark will read as an interlocking edit-frame device, not a generic boxed monogram.
- Playhead Amber will consistently mark edit points across section labels, project metadata, timeline rules, and CTAs.
- The lower services and contact sections will use distinct visual cuts so the page rhythm changes without losing restraint.
